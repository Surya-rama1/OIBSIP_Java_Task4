# Project Overview

The Online Examination System is a Java-based application designed to conduct online examinations in a simple and user-friendly manner.

The system allows users to log in, update their profile, attend an examination consisting of multiple-choice questions, navigate between questions, submit the examination, and view their results.

The application also includes a countdown timer to ensure that the examination is completed within the given time.

# Objective

The main objective of this project is to develop an interactive Online Examination System using Java.

The system demonstrates Java programming concepts, GUI development, event handling, user authentication, question management, timer functionality, and result calculation.

# Features

## 1. User Login

* User can enter their username and password.
* The system validates the login details.
* Access is provided only after successful authentication.

## 2. Profile Update

* User can view their profile.
* User can update profile information.

## 3. Online Examination

* Multiple-choice questions are displayed.
* Each question contains multiple options.
* User can select an answer.
* User can navigate between questions.

## 4. Countdown Timer

* A timer is displayed during the examination.
* The remaining examination time is continuously updated.
* The examination can be automatically submitted when the timer reaches zero.

## 5. Manual Submission

* User can submit the examination manually.
* The system calculates the result after submission.

## 6. Result Display

* The system displays the user's score.
* The result is shown after completing the examination.

# How the System Works

1. The application starts with the login screen.
2. The user enters the required login credentials.
3. After successful authentication, the user can access the examination system.
4. The user can view or update their profile and Then user starts the examination.
5. Multiple-choice questions are displayed one by one.
6. The user selects an answer for each question.
7. The countdown timer keeps track of the examination duration.
8. The user can navigate through the questions.
9. The examination can be submitted manually.
10. If the timer reaches zero, the examination is automatically submitted.
11. The system evaluates the selected answers.
12. The final score is displayed to the screen.
